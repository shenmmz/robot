## 二、两阶段回零流程

### 阶段一：串行预处理（stepSerial）

**目的**：避免机械干涉，确保 J3、J2、J5 依次移开原点

**优先级顺序**：J3(索引2) → J2(索引1) → J5(索引4)

**原因**：这三个轴在回零时可能会发生机械碰撞，必须先让它们移开原点位置，才能安全地进行后续回零。

```
stepSerial() 执行逻辑：

    ┌──────────────────┐
    │ J3 已移开原点？   │
    └────────┬─────────┘
             │
        ┌────┴────┐
        否        是
        │         │
        ▼         ▼
  处理J3轴    ┌──────────────────┐
  (返回)      │ J2 已移开原点？   │
             └────────┬─────────┘
                      │
                 ┌────┴────┐
                 否        是
                 │         │
                 ▼         ▼
           处理J2轴   ┌──────────────────┐
           (返回)     │ J5 已移开原点？   │
                     └────────┬─────────┘
                              │
                         ┌────┴────┐
                         否        是
                         │         │
                         ▼         ▼
                   处理J5轴    串行预处理完成
                   (返回)      m_serialPrehomeCompleted = true
```

### 阶段二：并行回零（stepParallel）

**目的**：6个轴同时执行回零，提高效率

**前提条件**：串行预处理完成（J2、J3、J5 已移开原点）

**特点**：
- 6个轴同时执行状态机
- 每个轴独立运行，互不阻塞
- 跳过已回零的轴

## 三、单轴状态机

### 3.1 状态枚举定义

| 状态 | 值 | 说明 |
|------|---|------|
| `HOME_INIT` | 0 | 初始化状态 |
| `HOME_CHECK_SENSOR` | 1 | 检查传感器状态 |
| `HOME_MOVE_AWAY_ORIGIN` | 2 | 移开原点 |
| `HOME_WAIT_MOVE_AWAY_ORIGIN` | 3 | 等待移开原点完成 |
| `HOME_MOVE_AWAY_REVERSE` | 4 | 移开反向限位 |
| `HOME_WAIT_MOVE_AWAY_REVERSE` | 5 | 等待移开反向限位完成 |
| `HOME_START_DATUM` | 6 | 开始回零 |
| `HOME_WAIT_DATUM` | 7 | 等待回零完成 |
| `HOME_SUCCESS` | 8 | 回零成功 |
| `HOME_FAIL` | 9 | 回零失败 |

## 四、硬件配置

### 4.1 轴硬件配置表（g_axis_hw）

| 轴 | axis | atype | dir | homeIn | negIn | 说明 |
|----|------|-------|-----|--------|-------|------|
| J1 | 0 | 1 | 1 | 0 | 1 | 原点IO=0，反向限位IO=1 |
| J2 | 1 | 1 | 1 | 2 | -1 | 原点IO=2，无反向限位 |
| J3 | 2 | 1 | -1 | 3 | -1 | 原点IO=3，无反向限位，方向反转 |
| J4 | 3 | 1 | 1 | 4 | 5 | 原点IO=4，反向限位IO=5 |
| J5 | 4 | 1 | 1 | 6 | -1 | 原点IO=6，无反向限位 |
| J6 | 5 | 1 | 1 | 7 | 8 | 原点IO=7，反向限位IO=8 |

**字段说明**：
- `axis`：轴号（0-5）
- `atype`：轴类型（1=旋转轴）
- `dir`：运动方向（1=正向，-1=反向）
- `homeIn`：原点传感器输入IO编号
- `negIn`：反向限位传感器输入IO编号（-1表示无）

### 4.2 回零策略配置表（g_home_strategy）

| 轴 | 移开原点 | 移开反向 | 速度 | 加速 | 减速 | 慢速 | S曲线 | 爬行 | 模式 |
|----|---------|---------|------|------|------|------|-------|------|------|
| J1 | -10° | -85° | 20°/s | 30°/s² | 50°/s² | 0°/s | 200ms | 0.5°/s | 3 |
| J2 | 38° | 0° | 20°/s | 30°/s² | 80°/s² | 0°/s | 200ms | 0.5°/s | 4 |
| J3 | -50° | 0° | 20°/s | 30°/s² | 80°/s² | 0°/s | 200ms | 0.5°/s | 3 |
| J4 | -10° | -200° | 20°/s | 30°/s² | 50°/s² | 0°/s | 200ms | 0.5°/s | 3 |
| J5 | 20° | 0° | 20°/s | 30°/s² | 50°/s² | 0°/s | 200ms | 0.5°/s | 4 |
| J6 | -10° | -220° | 30°/s | 50°/s² | 80°/s² | 0°/s | 200ms | 2.0°/s | 3 |

**字段说明**：
- `moveAwayOrigin`：移开原点的相对距离（正值正向移动，负值反向移动）
- `moveAwayReverse`：移开反向限位的相对距离
- `homeSpeed`：回零高速
- `homeAccel`：回零加速度
- `homeDecel`：回零减速度
- `homeLspeed`：回零慢速阈值
- `homeSramp`：S曲线过渡时间
- `homeCreep`：回零爬行速度
- `datumMode`：回零模式（3=正向限位回零，4=反向限位回零）

## 五、关键逻辑详解

### 5.1 传感器检测逻辑

```cpp
// 读取IO状态（已反转，1=未触发，0=已触发）
int homeTriggered = m_zmotionAPI->getDI(hw.homeIn);
int negTriggered = m_zmotionAPI->getDI(hw.negIn);

// 判断逻辑
if (!homeTriggered) {
    // 原点传感器被触发 → 需要移开原点
    state = HOME_MOVE_AWAY_ORIGIN;
} else if (hw.negIn >= 0 && !negTriggered) {
    // 反向限位被触发 → 需要移开反向限位
    state = HOME_MOVE_AWAY_REVERSE;
} else {
    // 传感器均未触发 → 可以开始回零
    state = HOME_START_DATUM;
}
```

### 5.2 轴空闲检测

```cpp
ZmotionResult idleResult = m_zmotionAPI->getAxisParamValue(hw.axis, IDLE);
if (idleResult.success && idleResult.piMultiValue == -1) {
    // 轴空闲（-1表示空闲）
}
```

### 5.3 回零完成检测

```cpp
ZmotionResult homedResult = m_zmotionAPI->getAxisSingleHomeStatus(hw.axis);
bool homed = homedResult.success && homedResult.axisHomeStatus == 1;
// axisHomeStatus == 1 表示回零成功
```

### 5.4 超时检测

```cpp
// 记录回零开始时间
startTime = QDateTime::currentMSecsSinceEpoch();

// 检查是否超时（默认180秒）
qint64 now = QDateTime::currentMSecsSinceEpoch();
if (startTime != 0 && (now - startTime) > m_homingTimeoutMs) {
    state = HOME_FAIL;
}
```

### 5.5 反向限位触发回退

在 `HOME_WAIT_DATUM` 状态下，持续监测反向限位：

```cpp
if (hw.negIn >= 0) {
    int negTriggered = m_zmotionAPI->getDI(hw.negIn);
    if (!negTriggered) {
        // 反向限位被触发 → 取消当前回零，移开反向限位
        m_zmotionAPI->singleAxisCancel({hw.axis}, 2);
        startTime = 0;
        state = HOME_MOVE_AWAY_REVERSE;
    }
}
```

## 八、调用示例

```cpp
// 在 RobotController 中调用
bool RobotController::executeHoming()
{
    if (!isConnected()) {
        emit operationFailed("回零", "硬件未连接");
        return false;
    }

    emit operationStarted("回零");
    return m_homingController->startHoming();
}

// 连接信号
connect(m_homingController, &HomingController::homingCompleted, this, []() {
    qDebug() << "所有轴回零完成！";
});

connect(m_homingController, &HomingController::homingFailed, this, [](const QString& msg) {
    qWarning() << "回零失败:" << msg;
});

connect(m_homingController, &HomingController::homingProgress, 
        this, [](int axis, HomeAxisState state) {
    qDebug() << "轴" << axis << "状态:" << state;
});
```

## 十、注意事项

1. **串行预处理必须完成**：J3、J2、J5 必须依次完成预处理后，才能进入并行回零阶段
2. **IO反转**：传感器信号需要反转后才能正确判断触发状态
3. **超时设置**：默认超时180秒，可通过 `setHomingTimeoutMs()` 修改
4. **轮询间隔**：默认200ms，可通过 `setPollInterval()` 修改
5. **停止回零**：调用 `stopHoming()` 会立即停止所有轴并发送急停命令
