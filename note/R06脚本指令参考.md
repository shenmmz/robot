# R06 脚本指令参考手册

> 格式：.rbt（纯文本 UTF-8）  
> 注释：`#` 开头的行为注释，不执行  
> 大小写不敏感，MOVEJ 和 movej 等效

---

## 指令速查

| 类别 | 指令 | 语法 | 用途 |
|---|---|---|---|
| **运动** | `MOVEJ` | `MOVEJ({J0..J5}, spd=250, acc=500, dec=600, timeout=8000)` | 关节空间运动 |
| | `MOVEL` | `MOVEL({X,Y,Z,Rx,Ry,Rz}, spd=250, ...)` | 笛卡尔直线运动 |
| | `MOVEOFF` | `MOVEOFF(10, 0, 0, 0, 0, 0)` | 关节空间相对偏移 |
| | `MOVELOFF` | `MOVELOFF(0, 50, 0, 0, 0, 0)` | 笛卡尔空间相对偏移 |
| **参数** | `SPEED` | `SPEED(250)` | 设全局默认速度 |
| | `ACCEL` | `ACCEL(500)` | 设全局默认加速度 |
| | `DECEL` | `DECEL(600)` | 设全局默认减速度 |
| | `TIMEOUT` | `TIMEOUT(8000)` | 设全局默认超时 |
| **等待** | `WAIT_IDLE` | `WAIT_IDLE()` | 等待所有轴停止（最多 30 秒） |
| | `DELAY` | `DELAY(500)` | 延时（毫秒） |
| **IO** | `SET_DO` | `SET_DO(0, 1)` | 设置 DO 输出 |
| | `WAIT_DI` | `WAIT_DI(0, 1, 5000)` | 等待 DI 输入 |
| **逻辑** | `FOR` | `FOR(i, 0, 9)` ... `END_FOR` | 计数循环 |
| | `WHILE_DI` | `WHILE_DI(0, 1)` ... `END_WHILE` | 条件循环 |
| | `IF_DI` | `IF_DI(0, 1)` ... [`ELSE`] ... `END_IF` | 条件判断 |
| **变量** | `SET` | `x = 100` 或 `x = y + 10` | 变量赋值，支持 + - * / |
| **工具** | `READ_POS` | `READ_POS()` | 读当前位置到控制台 |
| | `PRINT` | `PRINT("文本")` | 输出到控制台 |
| | `CALL` | `CALL("子程序.rbt")` | 调用子脚本 |

## 运动指令

### MOVEJ — 关节空间运动

```
MOVEJ({J0, J1, J2, J3, J4, J5}, spd=速度, acc=加速度, dec=减速度, timeout=超时)
```

切换到正解模式，6 个关节轴同时转动到目标角度。

### MOVEL — 笛卡尔直线运动

```
MOVEL({X, Y, Z, Rx, Ry, Rz}, spd=速度, acc=加速度, dec=减速度, timeout=超时)
```

切换到逆解模式，控制器自动 IK 解算，末端沿直线移动。

### MOVEOFF — 关节空间相对偏移

```
MOVEOFF(ΔJ0, ΔJ1, ΔJ2, ΔJ3, ΔJ4, ΔJ5)
```

从当前位置加上偏移量。例如 `MOVEOFF(10, 0, 0, 0, 0, 0)` = J0 转 10°。

### MOVELOFF — 笛卡尔空间相对偏移

```
MOVELOFF(ΔX, ΔY, ΔZ, ΔRx, ΔRy, ΔRz)
```

从当前笛卡尔位置加上偏移量。例如 `MOVELOFF(0, 50, 0, 0, 0, 0)` = Y 方向走 50mm。

### 运动参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `spd` | 25 | 速度（mm/s）：1–500 |
| `acc` | 50 | 加速度（mm/s²） |
| `dec` | 60 | 减速度（mm/s²） |
| `timeout` | 10000 | 等待到位超时（ms） |

参数可省略，使用全局或默认值。SPEED/ACCEL/DECEL/TIMEOUT 指令可覆盖全局默认。

## 参数指令

```
SPEED(250)       # 后续 MOVEJ/MOVEL/MOVEOFF/MOVELOFF 默认 speed=250
ACCEL(500)       # 默认 accel=500
DECEL(600)       # 默认 decel=600
TIMEOUT(8000)    # 默认 timeout=8000
```

设置后影响后面的运动指令（除非指令中显式写了 spd=xxx 参数）。写在一行，独立一行。

## 等待指令

### WAIT_IDLE — 等待轴停止

```
WAIT_IDLE()
```

轮询 6 个关节轴的 IDLE 状态，直到全部停止或 30 秒超时。模拟器下 IDLE 不可用时会跳过。

### DELAY — 延时

```
DELAY(500)
```

阻塞等待指定毫秒数（0–60000）。

---

## IO 指令

### SET_DO — 设置数字输出

```
SET_DO(编号, 值)
```

| 参数 | 说明 |
|---|---|
| 编号 | DO 端口 (0–19) |
| 值 | 0=低电平, 1=高电平 |

### WAIT_DI — 等待数字输入

```
WAIT_DI(编号, 期望值, 超时)
```

| 参数 | 说明 |
|---|---|
| 编号 | DI 端口 (0–19) |
| 期望值 | 0=等待低电平, 1=等待高电平 |
| 超时 | 最大等待 ms（默认 5000） |

超时不中止任务，输出 `[WARN] WAIT_DI X 超时` 继续执行。

## 逻辑控制

### FOR — 计数循环

```
FOR(变量名, 起始值, 结束值)       ← 步长固定为 1
FOR(5)                            ← 旧语法：重复 5 次 ($i=0..4)
    ...循环体...
END_FOR
```

```
FOR(i, 0, 9)                     ← i 从 0 到 9，每次 +1
    MOVEJ({i * 10, 0, 0, 0, 90, 0})
    WAIT_IDLE()
END_FOR
```

内置变量：`$i`（循环索引），`$n`（总次数，仅旧语法）。

### WHILE_DI — 条件循环

```
WHILE_DI(DI编号, 期望值)
    ...循环体...
END_WHILE
```

每轮循环结束时检查 DI 状态，满足条件则继续。例如 `WHILE_DI(0, 1)` = DI0 为高电平时保持循环。

### IF_DI — 条件判断

```
IF_DI(0, 1)                      ← DI0==1 时执行
    ...满足时执行的代码...
ELSE                             ← 可选
    ...不满足时执行的代码...
END_IF
```

## 变量

```
x = 100                          ← 常量赋值
offset = 50
x = x + 10                       ← 表达式（支持 + - * /）
name = $i * step                 ← 用循环变量
```

变量可在 MOVEJ/MOVEL 的坐标中直接使用：`MOVEJ({x, 0, 0, 0, 90, 0})`。

## 工具指令

### READ_POS — 读取当前位置

```
READ_POS()
```

输出当前关节角度和笛卡尔坐标到控制台。

### PRINT — 控制台输出

```
PRINT("到达点位A")
PRINT("当前 x = " + x)           ← 当前不支持字符串拼接
```

### CALL — 调用子脚本

```
CALL("sub_pick.rbt")
CALL("common/home.rbt")
```

加载并逐行执行子脚本，完成后返回主脚本继续。查找顺序：当前目录 → `config/scripts/` → 相对路径。

## 完整示例

```
# 设全局参数
SPEED(250)
ACCEL(500)
DECEL(600)

# 变量初始化
x = 0
step = 10

# 归位
MOVEJ({0, 0, 0, 0, 90, 0})
WAIT_IDLE()

# 循环走 10 个点位
FOR(i, 0, 9)
    x = i * step
    MOVEL({300, x, 300, 180, 0, 180})
    WAIT_IDLE()
    READ_POS()
    PRINT("点位完成")
END_FOR

# 条件判断
IF_DI(0, 1)
    SET_DO(1, 1)
    PRINT("DI0触发，DO1输出")
ELSE
    PRINT("DI0未触发")
END_IF

# 子程序调用
CALL("sub_place.rbt")

MOVEJ({0, 0, 0, 0, 90, 0})
WAIT_IDLE()
PRINT("任务完成")
```

---

## 注意事项

1. 坐标用花括号 `{ }` 包裹，逗号分隔，支持变量名和简单表达式
2. 命名参数（spd/acc/dec/timeout）可省略、可任意顺序
3. FOR/WHILE_DI/IF_DI 结尾必须对应 END_FOR/END_WHILE/END_IF
4. 运动指令后建议跟 `WAIT_IDLE()` 确保到位再执行下一步
5. 文件编码 UTF-8
