# 编程页功能规划

> 日期：2026-06-02
> 目标：升级编程页脚本编辑器，支持完整指令体系、指令按钮自动插入、文件管理、控制台输出。

---

## 一、脚本指令体系

| 类别 | 指令 | 格式示例 | 参数来源 |
|---|---|---|---|
| **运动-关节** | `MOVEJ` | `MOVEJ({0,0,0,0,90,0}, spd=25, acc=50, dec=60, timeout=8000)` | 关节角度: 读当前 DPOS；速度/加减速: 设置页默认值或调试面板值；超时: 设置页 |
| **运动-笛卡尔** | `MOVEL` | `MOVEL({306,0,495,180,0,180}, spd=25, acc=50, dec=60, timeout=8000)` | 笛卡尔: 读当前虚拟轴 DPOS |
| **等待** | `WAIT_IDLE` | `WAIT_IDLE()` | 无参数 |
| | `DELAY` | `DELAY(500)` | 用户输入毫秒数 |
| **IO-输出** | `SET_DO` | `SET_DO(0, 1)` | 用户选择 DO 编号(0–19) 和值(0/1) |
| **IO-输入** | `WAIT_DI` | `WAIT_DI(0, 1, 5000)` | DI 编号、期望值(0/1)、超时毫秒 |
| **回零** | `HOME` | `HOME()` | — |
| **输出** | `PRINT` | `PRINT("到达点位A")` | 用户输入文本 |
| **子程序** | `CALL` | `CALL("sub_move_to_home.r06")` | 同步调用另一个脚本文件，完成后继续 |
| **注释** | `#` | `# 这是注释` | 用户输入文本 |

### 指令执行行为

| 指令 | 执行逻辑 |
|---|---|
| `MOVEJ` | `switchToJointMode()` → `moveJ(targets, speed, accel, decel, timeout)` |
| `MOVEL` | `switchToCartesianMode()` → `moveL(targets, speed, accel, decel, timeout)` |
| `WAIT_IDLE` | `waitForAxesIdle({0..5}, 30000)` 等 6 关节全停 |
| `DELAY(ms)` | `QThread::msleep(ms)` + `processEvents` |
| `SET_DO(n, v)` | `ZmotionAPI::ZAux_Direct_SetOp(handle, n, v)` |
| `WAIT_DI(n, exp, t)` | 轮询 `getDI(n)` 直到 `== exp` 或超时 |
| `HOME()` | `RobotController::executeHoming()` |
| `PRINT("...")` | 追加到 `progConsoleOutput`，不阻塞 |
| `CALL("文件名.r06")` | 加载子脚本 → 逐行执行 → 全部完成后返回主脚本继续 |

## 三、指令按钮插入逻辑

每个按钮点击时，自动生成参数并插入到编辑器当前光标位置，末尾自动换行。

### MOVEJ / MOVEL

```
1. 读取当前坐标:
   - MOVEJ: RobotState::getAllAxisPositions()
   - MOVEL: RobotState::getAllCartesianPositions()

2. 读取默认运动参数:
   - speed:  设置页 spinDefaultSpeed  → 或调试面板 debugSpeed
   - accel:  设置页 spinDefaultAccel  → 或调试面板 debugAccel
   - decel:  设置页 spinDefaultDecel  → 或调试面板 debugDecel
   - timeout: 设置页 spinDefaultTimeout

3. 拼接:
   MOVEJ({0.000, 0.000, 0.000, 0.000, 90.000, 0.000}, spd=25, acc=50, dec=60, timeout=8000)
   MOVEL({306.000, 0.000, 495.000, 180.000, 0.000, 180.000}, spd=25, acc=50, dec=60, timeout=8000)

4. insertPlainText(cmd + "\n")
```

### SET_DO / WAIT_DI / DELAY

```
点击按钮 → 弹出 QInputDialog（获取数字）
  SET_DO:  输入 DO编号(0-19)、值(0/1)      → "SET_DO(3, 1)"
  WAIT_DI: 输入 DI编号、期望值、超时ms     → "WAIT_DI(0, 1, 5000)"
  DELAY:   输入等待毫秒                     → "DELAY(500)"
```

### HOME / WAIT_IDLE / PRINT

```
HOME():       直接插入 "HOME()"
WAIT_IDLE():  直接插入 "WAIT_IDLE()"
PRINT:        弹出 QInputDialog 获取文本   → "PRINT("到达点位A")"
#注释:        插入 "# " 并移动光标待输入
```

## 四、功能按钮

| 按钮 | 行为 | 说明 |
|---|---|---|
| **📂 加载** | `QFileDialog::getOpenFileName` → 读取 .txt 覆盖编辑器 | 标题栏显示文件名 |
| **📄 新建** | 确认未保存 → 清空编辑器 | 文件名重置为 "未命名" |
| **💾 保存** | 有路径→直接覆盖；无路径→另存为对话框 | — |
| **🗑 删除行** | 删除光标所在整行 | 使用 `QTextCursor::block` 操作 |
| **▶ 运行** | 解析脚本→构建指令列表→TaskExecutor 逐步执行 | 先检查控制器已连接 |
| **⏸ 暂停** | 联动已有暂停逻辑（`onProgStop`） | 弹出继续/停止对话框 |

## 五、脚本解析器扩展

当前 `onProgRun` 只解析 `MOVEJ(` 和 `MOVEL(`，需扩展为通用解析器。

```
逐行读取脚本:
  ├─ # 开头或空行 → 跳过
  ├─ MOVEJ(...)   → 提取 {j0..j5} + spd/acc/dec/timeout
  ├─ MOVEL(...)   → 提取 {x..rz} + spd/acc/dec/timeout
  ├─ WAIT_IDLE()  → 生成等待指令
  ├─ DELAY(ms)    → 提取毫秒数
  ├─ SET_DO(n,v)  → 提取编号和值
  ├─ WAIT_DI(n,exp,t) → 提取编号/期望/超时
  ├─ HOME()       → 生成回零指令
  └─ PRINT("...") → 提取文本

构建指令列表 → TaskExecutor 逐条执行
每步执行完 → emit 进度到控制台
```

### 指令数据结构

```cpp
struct ScriptCommand {
    enum Type { MoveJ, MoveL, WaitIdle, Delay, SetDO, WaitDI, Home, Print };
    Type type;
    QList<double> targets;     // MOVEJ/MOVEL 用
    double speed, accel, decel;
    int timeoutMs;
    int ioIndex, ioValue;      // SET_DO/WAIT_DI 用
    int delayMs;               // DELAY 用
    QString printText;         // PRINT 用
};
```

## 十、文件格式与脚本互调

### 文件格式

使用 `.rbt` 扩展名（Robot 缩写），本质是纯文本 UTF-8。

| 格式 | 辨识度 | 双击关联 | 手写编辑 | git diff |
|---|---|---|---|---|
| `.rbt` | 专属 | 可关联到 Robot_R06.exe | ✅ | ✅ |
| `.txt` | 无 | 记事本 | ✅ | ✅ |
| `.json` | 一般 | 一般 | ❌ | ✅ |

**默认保存路径**：`config/scripts/` 目录，用户也可自由选择任意路径。

### 脚本互调：CALL 指令

```
主脚本 main.r06:
  HOME()
  WAIT_IDLE()
  MOVEJ({0,0,0,0,90,0}, spd=40)
  CALL("sub_pick.r06")       ← 跳去执行子程序
  CALL("sub_place.r06")      ← 子程序返回后继续
  PRINT("完成")

子脚本 sub_pick.r06:
  MOVEL({306, 0, 495, ...}, spd=30)
  SET_DO(0, 1)               ← 夹爪闭合
  DELAY(200)
  MOVEL({306, 0, 300, ...}, spd=20)   ← 抬起来
```

**执行流程**：

```
main.r06 第4行 → CALL("sub_pick.r06")
  ├─ 暂停 main.r06（保存当前行号）
  ├─ 加载并解析 sub_pick.r06
  ├─ sub_pick.r06 逐行执行
  ├─ sub_pick.r06 全部执行完
  └─ 回到 main.r06，从第5行继续
```

**子脚本查找规则**：
1. 当前脚本所在目录
2. `config/scripts/` 目录
3. 绝对路径

**嵌套限制**：最多 10 层，防止无限递归。
