# Robot_R06 构建手册（Release）

## 首次构建

```powershell
# 1. 配置
& "C:\Program Files\CMake\bin\cmake.exe" -S "c:\Users\111\Desktop\Robot_R06" -B "c:\Users\111\Desktop\Robot_R06\build" -G "Visual Studio 18 2026" -A x64 -DCMAKE_PREFIX_PATH="C:\Qt\6.9.0\msvc2022_64"

# 2. 编译
& "C:\Program Files\CMake\bin\cmake.exe" --build "c:\Users\111\Desktop\Robot_R06\build" --config Release
```

## 改了代码后重新编译

```powershell
& "C:\Program Files\CMake\bin\cmake.exe" --build "c:\Users\111\Desktop\Robot_R06\build" --config Release
```

## 输出

`build\Release\Robot_R06.exe`，可直接运行。

## 如果换过 VS 版本或改了 CMakeLists.txt

```powershell
Remove-Item -Recurse -Force "c:\Users\111\Desktop\Robot_R06\build"
```

然后回到「首次构建」两步走。

> 注意：不要加 `-j` 参数。VS 生成器 + Qt AUTOMOC 并行编译会报 MSB8066 错误，本项目代码量不大，单线程编译一两分钟即可完成。

## 常见问题

### LNK1104：无法打开文件 Robot_R06.exe

程序还在运行，exe 文件被占用。先关掉再编译：

```powershell
Stop-Process -Name "Robot_R06" -Force
```

然后重新执行编译命令即可。
